# 周波数グループと路線（参考）

`ui/radio-presets.json` の各チャンネルの `lines` に、そのグループ（D1〜D7）を使っていることが確認できた線区を
「使用例」として入れています。アプリではチャンネル一覧のタイル・表と選択中チャンネルの詳細に表示され、
検索欄で路線名から絞り込めます。

- 公式な割当表ではなく、愛好家の受信報告やリポジトリ既存の変則割当メモから拾った**一部の例**です。
  記載のない線区も同じグループを使っていることがあり、古い情報が含まれる可能性もあります。
- 1 つのグループは「音声第1波・音声第2波・データ波」の 3 波で、地域ごとに隣接線区と重ならないよう使い分けられます。
  実際にどの波が聞こえるかは、その場所の線区で決まります。
- 「変則割当」の線区は、グループは同じでも周波数が標準と異なります（各チャンネルの注記を参照）。

## 追加・修正するには

`ui/radio-presets.json` の該当チャンネルの `lines` を書き換えます（同じグループの 3 波をそろえてください）。
組み込みを変えずに試すなら、同じ形式の JSON を「チャンネル一覧 → プリセットファイル」から読み込めます。
