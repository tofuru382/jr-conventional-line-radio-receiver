# JR-CLRR For Android（試験的）

デスクトップ版と同じ受信処理を Android で動かすための試験的なビルドです。
USB ドングルはアプリ内蔵のドライバーで直接動かします（入力方式「USB 直結（内蔵ドライバー）」）。
別アプリ「Rtl-sdr driver」経由の RTL-TCP（`127.0.0.1:1234`）も選べます。

## 必要なもの

- USB OTG（USB ホスト）に対応した Android 8.0 以降・arm64 のスマホ
- RTL-SDR ドングル（周波数ずれの少ない TCXO 付きを推奨）、OTG アダプター、350 MHz 帯で使えるアンテナ
- （RTL-TCP で使う場合のみ）[Rtl-sdr driver](https://f-droid.org/packages/marto.rtl_tcp_andro/)（`marto.rtl_tcp_andro`）

## APK の入手とインストール

1. GitHub の **Actions** → **Android APK** で最新の成功した実行を開き、
   **Artifacts** の `jr-radio-receiver-android-arm64` をダウンロードして展開します。
2. APK をスマホに送り、「提供元不明のアプリ」のインストールを許可して開きます。

リポジトリに署名鍵のシークレット（後述）がない場合、ビルドごとに使い捨ての鍵で署名されます。
その場合、新しいビルドを入れる前に古いアプリをアンインストールしてください（設定も消えます）。

## 使い方

1. ドングルをスマホに挿します。
2. 入力方式が **「USB 直結（内蔵ドライバー）」** になっていることを確認し、**受信を開始** を押します。
   初回は USB の使用許可を求められるので許可します。
3. 選択中のチャンネルの音声が再生されます。画面上部の **音声オン / ミュート中** ボタンで消音を切り替えられます。

ドングルを挿したときに「このアプリで開きますか」と聞かれたら、JR-CLRR を選んで「常に」にしておくと、
受信中にドングルが USB から外れて挿し直されたとき、許可なしで自動的に受信を再開します（最大 60 秒待ちます）。

Rtl-sdr driver を使う場合は、入力方式を「RTL-TCP サーバー」にして **RTL-SDR ドライバーを起動** を押し、
ドライバーが起動してから **受信を開始** を押します。

内蔵ドライバーは [rtlsdr-nusb](https://github.com/bastibl/rtlsdr-nusb)（Apache-2.0）を `crates/rtlsdr-nusb` に取り込み、
240 kS/s のサンプルレートと Android の USB ファイル記述子からの接続に対応させたものです。

Android 版の画面はデスクトップ版を簡略化しています。チャンネル一覧の検索欄はなく、一覧は詳細表示のみです。
各チャンネルには、[路線表](ROUTES.ja.md)からその周波数を使う路線名を表示します。

受信対象の波・聴いている波・自動選択のオン・オフは、受信プリセットごとにスマホに保存され、次に開いたときも引き継がれます。

受信する波は、**「路線から選ぶ」**（受信を停止中に押せます）で路線・区間を選ぶと、その区間の 3 波と旅客一斉情報をまとめて受信対象にできます。
複数の区間を一度に選べます。チャンネルごとのチェックで 1 波ずつ増減することもできます。

## 音声の復号について

選択波モニタの **「音声の復号器」** で、音声を作り直す復号器を v1.3・v1.4・v1.5 から選べます（受信を停止中に変更、端末ごとに記憶）。

| 復号器 | 声 | 処理の重さ（v1.3 比） |
| --- | --- | --- |
| v1.3（初期値） | 機械的 | 1 倍 |
| v1.4 | 中間（前後のつながりが自然な候補を選ぶ） | 約 7 倍 |
| v1.5（Mac 版の初期値） | もっとも自然（本来の CELP 方式を忠実に再現） | 約 20 倍 |

音声の復号は通話中だけ動きます。重い復号器で「処理欠落」が増え続ける場合は、受信する波を「路線から選ぶ」で
聴きたい路線の 3 波と旅客一斉情報に絞るか、軽い復号器に戻してください。v1.3 と v1.4 は元のアプリの
v1.3.0・v1.4.0 の復号器をそのまま使っています（`crates/jr-voice-lite`・`crates/jr-voice-v14`）。

近すぎて電波が強い場所では、受信設定の「ゲイン」を手動（20 dB 前後）にして「広帯域入力」がマイナスになるようにします。

## バックグラウンド受信

受信中は通知欄に「列車無線を受信中」が表示され、画面を消したり他のアプリに切り替えたりしても
受信・録音・音声再生が続きます（初回は通知の許可を求められます）。

- 音声は端末側で直接再生するため、バックグラウンドでも「通話を自動選択」による切り替えが続きます。
- 選択波モニタの「端末で直接再生」を外すと、デスクトップ版と同じ再生方式（画面表示中のみ）に切り替わります。音の聞こえ方を比べたいときに使います。
- 再生が通話の途中で途切れると、ためておく音声の量（再生の遅れ）を 0.4 秒から最大 1.6 秒まで自動で増やします。
  選択波モニタに「再生の途切れ ○回 · 再生の遅れ ○秒」と表示されます。遅れは増えますが、途切れにくくなります。
- 「テスト音を鳴らす」を押すと、選んでいる再生方式で「ポーン・ポーン・ポーン」と3回鳴ります。受信していなくても、音の出口が正常か確かめられます。
- 端末で直接再生するときは、端末本来のサンプリング周波数（多くは 48 kHz）で出力し、8 kHz の音声をアプリ内で変換します。
- 受信中に「戻る」を押すとアプリは閉じずに裏に回ります。受信を止めるには通知をタップしてアプリを開き、「受信を停止」を押してください。
- 最近使ったアプリの一覧からアプリを消すと受信も止まります。
- 機種によっては省電力機能がアプリを止めることがあります。その場合は設定でこのアプリの電池の最適化を「制限なし」にしてください。
- Rtl-sdr driver 側も動き続ける必要があります。

## 接続が切れたとき（自動再接続）

受信中に Rtl-sdr driver からのデータが止まったり接続が切れたりすると、状態が「**再接続中**」になり、
最大 60 秒間、2 秒おきに自動でつなぎ直します。ドライバーが応答しない場合は、アプリを開いている間に限り
ドライバーを自動で起動し直します（Android の制限で、裏に回っている間は他のアプリを起動できません）。
つながると「受信中」に戻り、録音もそのまま続きます。60 秒たってもつながらない場合は受信エラーになります。
ドライバーの画面に「found 0 device」と出るときは、ドングルが USB から外れています。挿し直してください。

## 無線機タブ

画面上部の **「無線機」** タブでは、無線機のような表示で次をまとめて確認できます（「詳細」タブで元の画面に戻ります）。

- 再生中のチャンネル（周波数・波の名前・路線）、通話受信（RX）・同期（SYNC）・録音（REC）・自動選択（AUTO / MAN）・消音（MUTE）の表示と信号品質
- 「◀ CH」「CH ▶」で受信対象の波を順に切り替え、「自動選択」で自動切替のオン・オフ
- 通話中の波の一覧（裏で録音中なら REC、再生中の波には「再生中」）。タップするとその波を聴きます
- 録音の状態と、最近の通話の履歴（アプリを開いている間に記録）

## 音量を自動でそろえる

選択波モニタの **「音量を自動でそろえる」** をオンにすると、小さい声（マイクから遠い運転士など）を最大 8 倍まで持ち上げ、
大きい声はそのままにします。声のない部分や雑音は持ち上げません。リアルタイム再生だけに働き、録音（WAV）は元の音量のままです。

## 録音を聞く

「録音・データ保存」の下の **「録音を聞く」** を開くと、保存した通話が一覧表示され、タップするとアプリ内で再生できます。
並び順は「新着順」「古い順」「チャンネル順」「保存した回ごと」から選べます。
録音のファイル名には周波数と波の名前が入ります（例：`352606250Hz-D7_音声第2波-000001.wav`）。
「ダウンロード」フォルダーのほか、ファイルアプリから見られないアプリ専用フォルダー（`Android/data/...`）の録音も表示します。
保存中のファイルは、保存を停止すると最後まで再生できます。

電波が弱いと通話の途中で同期が取り直され、細切れの WAV がたくさんできていました。
同じ波で 2 秒以内に続いた音声は 1 つの WAV にまとめ、1 秒未満の WAV（雑音を音声と誤って復号したもの）は削除します。
リアルタイム再生でも、前後に音声のない 0.16 秒未満の短い音は鳴らしません（「ブツ」という音の多くはこれです）。

通話がなかった回は何も保存しません（保存フォルダーも残しません）。データ電文などの JSONL を選んでいる場合は、その内容があれば保存します。

## 現時点の制限

- 画面の表示（同期状態や電文の一覧）はアプリを開いている間だけ更新されます。
- SoapySDR デバイスは選べません。ファイル・フォルダーの選択ボタンも非表示です（パスの手入力は可能）。
- 録音の既定の保存先は **「ダウンロード」フォルダーの `JR-CLRR/Recordings`** です（ファイルアプリから再生でき、アンインストールしても残ります）。
  Android 10 以前などで作れない場合は、アプリ専用フォルダー（`Android/data/io.jrradio.receiver/files/Music/…`、アンインストールで消える）を使います。
- 録音した内容や聞いた通信の内容を他人に漏らすことは電波法で禁じられています。

## 署名鍵を固定する（任意）

同じ鍵で署名すると、アンインストールせずに上書き更新できます。PC で鍵を作り、

```
keytool -genkeypair -keystore release.jks -alias jrradio -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks
```

リポジトリの Settings → Secrets and variables → Actions に次を登録します。

| 名前 | 値 |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | 上の base64 出力 |
| `ANDROID_KEYSTORE_PASSWORD` | キーストアのパスワード |
| `ANDROID_KEY_ALIAS` | `jrradio` |
| `ANDROID_KEY_PASSWORD` | 鍵のパスワード（キーストアと同じなら省略可） |
